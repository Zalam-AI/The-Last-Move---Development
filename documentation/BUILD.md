# THE LAST MOVE — building and shipping

## Requirements

| item | version | notes |
| --- | --- | --- |
| Godot | 4.6.3 stable | `https://github.com/godotengine/godot/releases/tag/4.6.3-stable` |
| Export templates | 4.6.3 stable | installed once into `~/.local/share/godot/export_templates/4.6.3.stable/` |
| Python (content pipeline only) | 3.11+ | numpy, scipy, soundfile, Pillow; `espeak-ng` and `ffmpeg` on PATH |

The game itself has no runtime dependencies and no plugins.

## Export presets

`export_presets.cfg` ships two presets:

- **Windows Desktop** → `dist/windows/TheLastMove.exe` (x86_64, embedded pck, one file)
- **Linux (verification)** → `dist/linux/TheLastMove.x86_64` (used to verify the *exported*
  bundle in CI, because a Windows binary cannot be executed in this environment)

Both exclude `tests/`, `tools/` and `documentation/`.

## Build a Windows release

```bash
godot --headless --path the_last_move --import
godot --headless --path the_last_move --export-release "Windows Desktop" \
      dist/windows/TheLastMove.exe
```

Output: a single ~110 MB `.exe` with the game data embedded. No installer is generated; for
Steam, upload the exe (or the folder) as the depot content.

### Verifying an export without Windows

The Linux preset produces the same project data and the same code path. Running it proves
the exported bundle boots, loads content, and finds its audio:

```bash
godot --headless --path the_last_move --export-release "Linux (verification)" \
      dist/linux/TheLastMove.x86_64
./dist/linux/TheLastMove.x86_64 --headless --quit-after 90
# [DB] loaded 53 items, 8 properties, 16 upgrades, 8 modifiers
# [Audio] 102 sfx clips, 8 music, 10 ambience, 29 voice
```

This check exists because audio is loaded from a manifest
(`assets/audio/manifest.json`): in an exported `.pck`, imported file names differ from
source file names, and a directory scan silently loses half the clips. The manifest is
generated by `tools/build_audio_manifest.py` and verified by `test_runner.tscn`.

## Regenerating content

```bash
python3 tools/generate_audio.py          # ~100 s: 199 wavs -> ogg for loops
python3 tools/build_audio_manifest.py    # refresh the audio manifest (required)
```

Do **not** run `generate_audio.py --no-ogg`: it regenerates 44 MB of WAV sources that the
ogg pass deliberately deletes after compression.

## Steam checklist (prepared, not performed)

These steps require a Steamworks partner account, an app id, and financial/legal details.
None of them have been done here, and none of them are faked in the build.

1. **Create the app** in Steamworks → note the app id.
2. **Depots:** one Windows depot; content = the folder containing `TheLastMove.exe`.
3. **Launch options:** executable `TheLastMove.exe`, working directory empty, OS Windows.
4. **Steam transport:** add the Steamworks bindings, implement `steam_transport.gd`
   against `Net.create_host/join/leave`, set `Net.transport = "steam"`. Until this is done
   the game ships with direct-IP ENet, which works but has no NAT punch-through.
5. **Lobbies/rich presence:** wire Steam lobbies to the existing lobby UI.
6. **Achievements:** the 11 achievements in `resources/flavor.json` map 1:1 to Steam
   achievement API names; call `Steamworks.setAchievement(id)` from
   `Save.set_achievement()`.
7. **Steam Voice:** optional. The built-in proximity voice works without it; Steam Voice
   would replace the capture layer only.
8. **Store page:** capsule art, screenshots from four-player sessions, trailer, and a
   content survey (fantasy violence is mild and non-graphic; the mature-content question is
   about dread, not gore).
9. **Build upload:** `steamcmd +login <account> +run_app_build ../scripts/app_build_<appid>.vdf`.
10. **Branch to default only after** the manual QA in `MANUAL_ASSET_TASKS.md` is signed off.

## Version numbering

`project.godot` carries `config/version="1.0.0"`. `Net.PROTOCOL` is a separate integer and
must be bumped whenever an RPC signature changes; mismatched builds are kicked with a
readable message rather than desyncing.

## Repository layout for a release

```
dist/windows/TheLastMove.exe     ship this
dist/linux/TheLastMove.x86_64    verification artefact, not shipped
assets/                          source of all audio (game loads via manifest)
documentation/                   ships with the repo, not in the depot
tests/, tools/                   excluded from the export
```
