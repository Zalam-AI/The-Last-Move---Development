# THE LAST MOVE

A first-person co-op physics comedy for 1–4 players. You work for a moving company that
relocates people out of houses that do not want to be relocated.

Carry the furniture. Mind the doorways. Do not talk to the family.

- **Engine:** Godot 4.6.3 (GDScript, Forward+ renderer)
- **Platform:** Windows 64-bit (Steam transport layer stubbed behind an interface)
- **Players:** 1–4, host-authoritative ENet multiplayer, drop-in/out
- **Content:** 8 handcrafted properties, 53 furniture items, 8 contract modifiers,
  16 upgrades (all functional), 4 supernatural creature types, 11 achievements, 31 scripted
  supernatural events, full campaign with an ending
- **Onboarding:** no tutorial level; a hint director teaches one mechanic at a time, once per
  save profile, in dispatch's voice — switchable off in Settings

---

## Run it from source

```bash
godot --path the_last_move                 # editor + play
godot --path the_last_move --headless --quit-after 120    # smoke boot (CI)
```

`godot` must be 4.6.3. The project has no external dependencies, no plugins, and no
imported binary art: every mesh, texture-free material and sound effect is generated by
the code in this repository.

## Build a Windows release

See `documentation/BUILD.md`. Short version:

```bash
godot --headless --path the_last_move --export-release "Windows Desktop" build/TheLastMove.exe
```

## Test it

```bash
godot --headless --path . res://tests/test_runner.tscn     # systems + content integrity
godot --headless --path . res://tests/level_audit.tscn      # all 8 properties, spawn validity
godot --headless --path . res://tests/carry_test.tscn       # carry physics with real forces
godot --headless --path . res://tests/systems_test.tscn     # modifiers, upgrades, economy, events
godot --headless --path . res://tests/creature_test.tscn    # creature AI end to end
godot --headless --path . res://tests/campaign_test.tscn    # 8-property campaign run
bash tools/mp_test.sh 3 26                                  # 1 host + 3 clients, separate processes
```

`bash tools/build_all.sh` runs all six suites, the 3-process multiplayer test, both exports
and a boot check of the exported bundle in one pass, and prints `BUILD OK` only if every step
passes. Current status of every suite is recorded in `documentation/TESTING.md`.

## Licences and originality

All code in this repository was written for this project. All audio is synthesised from
scratch by `tools/generate_audio.py` (oscillators, filtered noise, espeak-ng for the PA
announcer). All 3D content is built at runtime from primitives by
`scripts/core/asset_lib.gd` and `scripts/core/mesh_builder.gd`.

No assets, audio, level layouts or design data from any commercial game — including but
not limited to PEAK, R.E.P.O., Lethal Company, Phasmophobia or Viscera Cleanup Detail —
have been copied, extracted, or used as a reference for specific art or sound. The design
is an original take on the co-op physics-comedy genre: a moving company, a hostile house,
and the specific misery of fitting a sofa through a doorway built for smaller people.
